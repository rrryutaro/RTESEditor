# RTESEditor

TES（The Elder Scrolls）シリーズの ESP/ESM ファイルを編集するための統合エディタです。  
現在は **Morrowind（TES3）** に対応しており、OpenMW の UTF-8 MOD にも利用できます。

---

## ダウンロード（EXE版）

Python のインストール不要で使えるスタンドアロン EXE は、[Releases](../../releases) からダウンロードできます。

---

## 特徴

- ESP / ESM バイナリファイルの読み込み・表示・編集・保存
- 複数ファイルの同時読み込みと競合表示（Conflict View）
- エンコーディング対応：CP1252（英語版）/ Shift-JIS（日本語版）/ UTF-8（OpenMW）
  - ファイル読み込み時に自動判定
  - ファイルごとに個別指定可能
- Shift-JIS 日本語版特有のトレイルバイト `0x40 ↔ 0x7F` 変換に対応
- レコードタイプごとの列表示カスタマイズ（列ヘッダ右クリックで設定・永続保存）
- Mod ファイル読み込みパターンの登録・呼び出し
- TSV エクスポート / インポート
- ローカライズ JSON エクスポート / インポート
  - 会話本文、書籍本文、表示名、説明文などの翻訳用
  - 会話結果スクリプト / 通常スクリプトの表示系コマンド内にある引用文字列を個別エントリとして抽出
- テーマ切り替え（標準 / ダーク）
- フォント設定
- 検索（Ctrl+F）
- 常に最前面表示

## 使い方

詳細は [Wiki](../../wiki) を参照してください。

### ファイルの読み込み

「ファイル → 開く」からファイルを追加します。複数ファイルを同時に登録できます。

| 列 | 説明 |
|----|------|
| エンコード | ファイルのエンコーディング（自動判定後に変更可） |
| 上書き | 複数ファイルで同一レコードが競合した際にこのファイルを優先表示する |
| 保存対象 | 「保存」「名前を付けて保存」の保存先とし、競合ビューでの編集を許可する |
| 検索対象 | 全体検索の対象とする |

読み込みダイアログ上部の「パターン」から、現在の一覧を名前付きで登録し、あとから呼び出せます。

### 保存

| メニュー | 動作 |
|---------|------|
| ファイル → 保存 | 「保存対象」ファイルを元のパスに上書き保存（確認ダイアログあり） |
| ファイル → 名前を付けて保存 | 「保存対象」ファイルを別名で保存 |
| ファイル → 修正箇所のみ書き出し | 今セッションで編集したレコードのみを指定ファイルへ書き出す。既存ファイルを指定した場合はマージ（既存 + 新修正） |

### TSV エクスポート / インポート

「ファイル → エクスポート (TSV)」「ファイル → インポート (TSV)」で一括編集が可能です。

### ローカライズ JSON

「ファイル → エクスポート (ローカライズJSON)」で、翻訳対象の文字列を JSON に書き出します。
各エントリの `translation` に訳文を入れてから「ファイル → インポート (ローカライズJSON)」で読み込むと、対象フィールドを UTF-8 として更新します。

対象には、アイテム名、セル名、会話本文、書籍本文、説明文、会話結果スクリプトや通常スクリプト内の `MessageBox` / `Choice` 表示文字列などを含みます。
ID、モデルパス、アイコンパス、スクリプト名、サウンド名、配置参照のオブジェクトIDやセル参照名など、翻訳すると参照が壊れやすい文字列は対象外です。

注意: `SCPT.SCTX` は全文を翻訳対象にせず、表示コマンドの引用文字列だけを抽出します。OpenMW はスクリプト本文をコンパイルして実行するため OpenMW 向けの翻訳に利用できますが、Morrowind 本体向けに `SCDT` との整合まで保証する機能ではありません。

## 動作環境（Python 版）

- Python 3.11 以降
- PySide6

## インストール（Python 版）

```bash
pip install PySide6
```

## 起動方法（Python 版）

```bash
python main.py
```

---

## ビルド（EXE 生成）

```bash
pip install pyinstaller
cd RTESEditor
pyinstaller RTESEditor.spec --noconfirm
```

または `RTESEditor/build_exe.bat` をダブルクリックしてください。  
生成された EXE は `RTESEditor/dist/RTESEditor.exe` に出力されます。
