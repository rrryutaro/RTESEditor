# RTESEditor

TES（The Elder Scrolls）シリーズの ESP/ESM ファイルを編集するための統合エディタです。  
現在は **Morrowind（TES3）** に対応しており、OpenMW の UTF-8 MOD にも利用できます。

---

## ダウンロード（EXE版）

Python のインストール不要で使えるスタンドアロン EXE は、[Releases](../../releases) からダウンロードできます。

---

## 特徴

- ESP / ESM バイナリファイルの読み込み・表示と、別パッチESPによる安全な編集
- 複数ファイルの同時読み込みと競合表示（Conflict View）
- エンコーディング対応：CP1252（英語版）/ Shift-JIS（日本語版）/ UTF-8（OpenMW）
  - ファイル読み込み時に自動判定
  - ファイルごとに個別指定可能
- Shift-JIS 日本語版特有のトレイルバイト `0x40 ↔ 0x7F` 変換に対応
- レコードタイプごとの列表示カスタマイズ（列ヘッダ右クリックで設定・永続保存）
- Mod プロジェクト（参照元一覧 + 編集先パッチ）の登録・呼び出し
- 持ち運び可能な `.rteproj` プロジェクトファイルの読み込み・保存
- 編集先パッチ専用タブ
  - パッチに含まれるレコードの確認
  - 参照元と編集先のフィールド差分表示
  - 不要なオーバーライドの除去
  - `DELE`によるゲーム内削除指定と解除
  - 孤立 INFO への親 DIAL の手動指定
  - 保存前検証
- TSV エクスポート / インポート
- ローカライズ JSON エクスポート / インポート
  - 会話本文、書籍本文、表示名、説明文などの翻訳用
  - 会話結果スクリプト / 通常スクリプトの表示系コマンド内にある引用文字列を個別エントリとして抽出
- テーマ切り替え（標準 / ダーク）
- フィールド編集の Undo / Redo（Ctrl+Z / Ctrl+Y）
- オーバーライドの作成・除去とゲーム内削除指定の Undo / Redo
- フォント設定
- 検索（Ctrl+F）
- 常に最前面表示

## 使い方

詳細は [Wiki](../../wiki) を参照してください。

### ファイルの読み込み

「ファイル → 開く」から、参照元と編集先パッチを追加します。参照元は常に読み取り専用で、直接変更されません。

| 列 | 説明 |
|----|------|
| エンコード | ファイルのエンコーディング（自動判定後に変更可） |
| 役割 | 「参照元（読取専用）」または1つだけ指定できる「編集先パッチ」 |

「既存パッチを追加」では以前作成した修正版ESPを開き、追加修正を追記できます。「新規パッチを指定」では、保存時に新しいESPを作成します。編集対象を選んで適用すると、必要なレコードが編集先パッチへ自動的にコピーされます。

編集先パッチは常にロード順の最後です。読み込みダイアログ上部の「プロジェクト」から、参照元一覧・ロード順・エンコード・編集先パッチを名前付きで登録し、あとから呼び出せます。

一覧を別PCや別フォルダーへ持ち運ぶ場合は「現在を `.rteproj` へ保存」を使用します。同じドライブ上のファイルはプロジェクトファイルからの相対パスで保存されます。

プロジェクトを開いたときに参照元が見つからない場合は、該当行が赤く表示されます。行を選び「選択ファイルの場所を変更」から移動後のESM/ESPを割り当て直せます。

「新規パッチを指定」した場合だけ、存在しない編集先を新規ESPとして作成します。「既存パッチを追加」または既存の `.rteproj` で指定したパッチが見つからない場合は赤く表示して読み込みを停止するため、移動した既存パッチを誤って空のESPとして作り直しません。

新しいプロジェクトの読み込みが途中で失敗した場合は、現在開いているプロジェクトと表示内容を維持します。

会話の INFO を編集した場合は、所属する DIAL も編集先パッチへ含めて `DIAL → INFO` の順に保存します。親 DIAL を特定できない INFO は保存を拒否するため、OpenMW に無視される孤立 INFO を新たに作りません。

自動的に親 DIAL を決定できない既存 INFO は「編集先パッチ」タブで赤く表示されます。「親DIALを指定」から参照元の候補を選択できます。

「編集先パッチ」タブでは、パッチに含まれるレコードだけを確認できます。「選択したオーバーライドを除去」を実行すると編集先パッチからのみ削除され、参照元の状態へ戻ります。

「ゲーム内で削除扱い」は、参照元を残したまま編集先パッチへTES3の `DELE` フィールドを追加します。これはパッチから修正を取り除く「オーバーライドの除去」とは異なります。共通タブのレコード行を右クリックして、オーバーライドの明示的なコピー、ゲーム内削除指定、削除指定の解除を実行できます。

同タブの下段には選択レコードのフィールド差分を表示します。文字列は各ファイルのエンコードで解釈した表示値を比較するため、Shift-JISからUTF-8への変換だけでは修正差分として扱いません。

テキスト編集、TSV取り込み、ローカライズJSON取り込みによるフィールド変更に加え、オーバーライドの作成・除去、ゲーム内削除指定も「編集 → 元に戻す」「編集 → やり直す」で操作できます。最初の編集を元に戻したときは、その編集のためだけに自動作成されたオーバーライドも一緒に除去されます。保存すると、その時点までの編集履歴は確定されます。

### 保存

| メニュー | 動作 |
|---------|------|
| ファイル → 保存 | 編集先パッチだけを保存。参照元ESM/ESPは変更しない |
| ファイル → 名前を付けて保存 | 編集先パッチ全体を別名で保存し、以後そのファイルを更新する |

既存パッチを保存すると、保存前の内容を同じフォルダーの `<パッチ名>.bak` にバックアップします。新しい内容は一時ファイルへ完全に書き込んでから置き換えるため、書き込み途中の不完全なESPが残りにくい方式です。

未保存の変更がある状態で別のプロジェクトを開くか終了すると、「保存」「破棄」「キャンセル」から選択できます。

保存前には、孤立 INFO、重複レコード、存在しない DIAL を参照する `AddTopic`、不足している `MAST` を検証します。エラーは保存を停止し、警告は確認後に保存を続行できます。

### TSV エクスポート / インポート

「ファイル → エクスポート (TSV)」「ファイル → インポート (TSV)」で一括編集が可能です。

### ローカライズ JSON

「ファイル → エクスポート (ローカライズJSON)」で、翻訳対象の文字列を JSON に書き出します。
各エントリの `translation` に訳文を入れてから「ファイル → インポート (ローカライズJSON)」で読み込むと、対象フィールドを編集先パッチの指定エンコードで更新します。

対象には、アイテム名、セル名、会話本文、書籍本文、説明文、会話結果スクリプトや通常スクリプト内の `MessageBox` / `Choice` 表示文字列などを含みます。
ID、モデルパス、アイコンパス、スクリプト名、サウンド名、配置参照のオブジェクトIDやセル参照名など、翻訳すると参照が壊れやすい文字列は対象外です。

注意: `SCPT.SCTX` は全文を翻訳対象にせず、表示コマンドの引用文字列だけを抽出します。OpenMW はスクリプト本文をコンパイルして実行するため OpenMW 向けの翻訳に利用できますが、Morrowind 本体向けに `SCDT` との整合まで保証する機能ではありません。

## 動作環境（Python 版）

- Python 3.11 以降
- PySide6

## インストール（Python 版）

```bash
pip install PySide6
```

## 起動方法（Python 版）

```bash
python main.py
```

---

## ビルド（EXE 生成）

```bash
pip install pyinstaller
cd RTESEditor
pyinstaller RTESEditor.spec --noconfirm
```

または `RTESEditor/build_exe.bat` をダブルクリックしてください。  
生成された EXE は `RTESEditor/dist/RTESEditor.exe` に出力されます。
